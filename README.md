# Enterprise Supply Chain Predictive Pipeline & Financial Risk Dashboard

## 📊 Business Problem & Executive Summary
In global logistics, a delay isn't just an operational failure—it's a direct threat to working capital and customer retention. This project utilizes the **DataCo Smart Supply Chain Dataset (180,519 records)** to engineer an end-to-end data product. 

By utilizing Machine Learning, this system predicts supply chain delivery delays and maps failure probabilities directly against transaction revenue. This process isolates **$20.14 Million in "Revenue at Risk"**, transforming raw data into actionable insights for operational managers and C-suite executives.
